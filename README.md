Overview
This Power BI Dashboard provides an interactive visualization of Spotify's most-streamed songs in 2024.

Features
Top Tracks & Artists: A ranked list of the most-streamed songs and their performers.
Streaming Trends: Insights into monthly and regional streaming patterns.
Genre Analysis: Breakdown of popular genres.
Usage
Open the .pbix file in Power BI Desktop, refresh the data, and explore the interactive visuals.

Dataset
The dataset includes song names, artists, stream counts, genres, release dates, and regional data for 2024.
